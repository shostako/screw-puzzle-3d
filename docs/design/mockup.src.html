ネジ外し3D 見た目の案

A おもちゃブロック調をベースに、ねじを六角穴付きボルト（キャップボルト）にしました。盤面は今の生成器が作った実際のステージです。指で回せます。

盤面 A ベース

ねじ：カラーのキャップボルト

六角穴付きボルト風

頭
円筒頭。頭の径はねじ径の約1.5倍、頭の高さはねじ径とほぼ同じ（JIS B 1176 の比率に寄せた）
側面
ローレット（縦の細かい溝）。上の角は面取り
穴
六角穴。底は暗くして、どの向きからでも穴だと分かるように
色
アルマイト調のカラー。金属の映り込みは残しつつ、色ははっきり出す
外すとき
六角レンチで回すように頭が回り、ねじ部が抜けてから箱へ飛ぶ

いまの丸頭（半径 0.3）と当たり判定の大きさは同じにして、見た目だけ替えます。ルールと生成器には触りません。

マスコット：ネジまる（立体版） 見本から作り直し

待機

キャップボルトの子

見本
Codex（ChatGPT の枠）で作った4枚の絵を下敷きに、立体に起こした
頭
金色アルマイトのキャップボルト頭。縦のローレット、面取り、深い六角穴
顔
茶色の瞳の大きな目、太めの眉、口を開けた笑顔、ピンクのほっぺ
体
銀のねじ部が胴。白いソフビの腕と手袋、銀の脚、青い靴に白い靴底
成功
^ ^ の目でバンザイして回転ジャンプ、紙ふぶき
失敗
× の目とへの字口、頭を傾けて汗、レンチを下げる

three.js の基本形の組み合わせで、外部の読み込みはありません。そのままアプリに入れられます。

造形と、層を踏まえたねじの置き方

層の約束

層ねじ置き方
0 装飾1〜21本で留めてぶら下げ、下のねじを隠す
1 外板2〜4四隅寄り・外向き。最初の向きで半分ほど見える
2 骨組み2〜3外板の陰か内向きの面。外板を1枚外すと届く
3 芯3〜4最後に残る板。どの外板からも隠れる位置

層の番号は手で決めず、「その板のねじに届くまでに外す必要のある板の数」を今の安全側の隠れ判定（safeBlocker）で数えて決めます。

生成の流れとランダム

  1. 題材ごとのテンプレート（車・家・動物など）で部品の木を組む。部品は板に加えて円柱や丸めた箱などの凸形。
  2. 層を数え、層ごとの本数と向きの表どおりにねじを置く。
  3. 今の peelable → solve → 色の割り当てで解けることを確かめる。
  4. 待機スロットを使う回数などで難しさを測り、ステージの条件に足す。
  5. ランダムは「おまかせ」→「今日の1問」（日付がシード）→ 難しさをそろえる、の順。

進め方の案

項目中身
D1 見た目の土台A の材質・光・背景・HUD と、キャップボルトのねじ。テーマは1か所の表にまとめる
D2 分解の演出ボルトが回って抜け、箱へ飛ぶ。板がはじけて落ちる。箱が満杯で閉じる
D3 マスコットネジまるの待機・成功・失敗・応援。ゲームの合図（feedback.js の名前）につなぐ
D4 部品の木と題材凸形の部品を足し、車・家・動物のテンプレートを2〜3種
D5 層つきのねじ配置層の計算と層ごとの約束。難しさの数値をステージ条件に
D6 ランダム「おまかせ」と「今日の1問」

決めてほしいこと

ネジまるをこの形で決めてよいですか。よければ ROADMAP に D1〜D6 を足して、D1 から作り始めます。

前回の調査（似たアプリの傾向）
  • 木の板＋派手な色のねじ。色はねじにだけ載せて、色合わせの対象をはっきりさせる。
  • 層が重なった盤面（木の構造の上に金属板）。外側から外す順番がパズルになる。
  • 題材は車・家・動物・立方体の塊。「どれも立方体」という不満レビューもある。
  • 外れた部品が飛ぶ・落ちる気持ちよさと、クリック音・振動が評価されている。
  • 調べた範囲ではマスコットを立てたものは見当たらない。
