# 判断の記録

技術や見た目の判断と、その理由を1〜2行で残す。新しいものを下に足す。

- 2026-10-03 ルールは描画と物理から切り離した純粋なモジュールにする。ルールと解ける保証をブラウザ無しのテストで守れるようにするため（ROADMAP の M2）。
- 2026-10-03 盤面の生成器は、2D 版と同じく物理を安全側に見積もった探索で解ける手順を確かめる。実際の物理は揺らぐので、探索が楽観的だと解けない盤面が出るため（ROADMAP の M6）。
- 2026-10-03 3D 描画は three.js。WebGL の薄い層で、板・円柱・光の基本がそろい、物理ライブラリ（M5）とも組みやすい。Babylon.js より軽く、React 等の枠組みは要らない規模のため。
- 2026-10-03 ビルドは Vite（`base: './'`）。npm のライブラリを1つの JS に同梱でき、相対パスなので Pages のサブパスでも Capacitor の中でも同じ `dist/` が動くため。
- 2026-10-03 テストは Vitest。Vite と同じ ES モジュールの書き方のままブラウザ無しで速く回るため。
- 2026-10-03 立体の回し方は、カメラを固定して立体のほうをカメラから見た軸で回す（トラックボール式）。OrbitControls のような上下の制限が無く、裏も底も同じ指の動きで見られるため。
- 2026-10-03 タップの判定は、動き 10px 以内かつ 350ms 以内、2本目の指が触れた操作はタップにしない。回しているつもりでねじを外さないことを優先した値で、M8 で実機に合わせて詰める。
- 2026-10-03 スクリーンショットは playwright-core と既に入っている Chromium（`/opt/pw-browsers`）で撮る。ブラウザの取得を伴わず、ヘッドレスでも SwiftShader で WebGL が描けるため。CI では撮らない（ブラウザの用意が要るため）。
- 2026-10-03 ルールの状態は書き換えずに新しい状態を返す形にする。戻る・ヒント・解ける保証の探索が、状態を写して試すだけで済むため。
- 2026-10-03 詰みは「外せるねじが1本も無い」とする。3D では待機スロットに空きがあっても全部のねじが隠れうるため。2D 版の定義はこの特別な場合。
