# ねじ外しパズル 3D 版 仕様

2D 版（[shostako/screw-puzzle](https://github.com/shostako/screw-puzzle)、公開ページ https://shostako.github.io/screw-puzzle/ ）を発展させた3D版。

## 核になる遊び

- 盤面は1個の立体。箱や家具のような形が、何枚もの板とそれを留めるねじで組まれている。
- 指で立体を回して、表・裏・側面のどこにあるねじも外す。ねじの位置を探して回すこと自体が遊びの半分になる。
- 外したねじは、2D 版と同じく色の箱と待機スロットに入る。

## 2D 版から引き継ぐルール

細部は 2D 版の `index.html` と README の「現在のルール」が正本。

- 上に色つきの箱が2つ。ねじをタップすると、同じ色で空きのある箱に入る。3本で満杯になると消え、次の箱が出る。
- 合う箱が無いねじは待機スロット（5個）へ。新しい箱が出たら、スロットの同じ色のねじは自動で移る。
- 全部の箱を埋めたらクリア。スロットが満杯で、入れられるねじが無ければ詰み。
- 板を留めるねじが2本以上なら固定、1本になるとそのねじを軸に回ってぶら下がり、0本で落ちる。
- 部品に親子があるとき（題材の車輪と車体、札と載っている板など）、子の部品が残っている間は親の最後のねじは外せない（子が付いた親は落ちない。D5）。
- 盤面は生成器が作り、解ける手順があることを保証する。

## 3D で決め直すところ

- 隠れたねじ: ねじが抜ける向き（頭の側、軸の外向き）に他の板が少しでも重なっていれば外せない。タップすると震えて拒否する。
- 操作: 1本指のドラッグで立体を回す。ドラッグとタップは区別し、回しているつもりでねじを外さない。2本指で拡大・縮小。
- 落ちた板やぶら下がった板は、3D の物理で動く。ぶら下がった板が他の板に当たって止まり、その下のねじを隠し続けることもある。
- ねじは、どの向きから見ても色と形が分かる見た目にする。

## 作り方の前提

- スマホのブラウザで遊べる Web の単一ページとして作る。最終的には 2D 版と同じく Capacitor で包んで Android アプリにする。
- タッチ操作が前提。縦画面。
- 使うライブラリ（3D 描画、物理）は自由に選んでよい。選んだ理由は `docs/DECISIONS.md` に残す。
- アプリとして包むときにネットが無くても動くよう、外部の読み込みは最終的に同梱できる形にしておく。

## 後回しでよいもの

2D 版にあるヒント、詰みから戻る、クリアの評価、演出、設定、キャラクターは、核の遊びが動いてから順に足す。
