# 実機で見てほしい点

ヘッドレスのブラウザでは分からない、手触り・見え方・音・重さのうち、実機（スマホのブラウザか Android アプリ）で確かめてほしい点を1行ずつ書く。各スレッドは足すだけで、実機の確認を待たずに先へ進む。確かめたら行頭の `[ ]` を `[x]` にし、気づいたことを後ろに書く。

書き方: `- [ ] （項目）何を・どう見てほしいか`

## 仕上げ（E）の前から残っている点

- [ ] （D2）ねじが回りながら抜ける演出と、板がはじけて落ちる演出が、重くならずになめらかに見えるか
- [ ] （D3）左下のネジまるの待機の動き（瞬き・揺れ）が、盤面を回している時にカクつかないか
- [ ] （設定）回す速さ「ゆっくり・ふつう・はやい」の差が指で分かるか。「ふつう」が速すぎ・遅すぎでないか
- [ ] （設定）画質「軽い」で、ねじの頭の見た目（ローレットなし）が安っぽく見えすぎないか
- [ ] （M8）ねじのタップが、ねじの中心から少し外れても狙ったねじで外れるか（指の太さで外しにくいねじが無いか）
- [ ] （M8）振動の強さと長さ（外す・外せない・箱が満杯・クリア）がうるさすぎないか
- [ ] （E 棚卸し）クリアのカードで、跳ねるネジまるが上の案内の文字に重なって見えるか（ヘッドレスでは重なった）

## 仕上げ（E）

- [ ] （E6）ねじを外すときのカチカチ→ポンが、ねじが回って抜ける動きとずれずに聞こえるか。連打したときにうるさすぎないか
- [ ] （E6）箱に入るカチッ・待機スロットの音・箱が閉まるパタン・板が落ちるコトン（大きい板ほど低い）が聞き分けられるか
- [ ] （E6）クリアのジングルが他の音より目立ち、BGM が下がって聞こえるか
- [ ] （E6）BGM の大きさが効果音の邪魔にならないか。約 19 秒のループが飽きないか、つなぎ目で途切れないか
- [ ] （E6）アプリを裏に回すと BGM が止まり、戻すと再開するか（Android アプリとスマホのブラウザの両方）。設定の「BGM 切」が再読み込みの後も残るか
- [ ] （E6）スマホのスピーカーで、どの音も割れたり、低い音（コトン・パタン）が聞こえなくなったりしないか
- [ ] （E2）板が接する所の暗さ（札の周り・窓の周り・車輪の付け根）が、回している時に汚れやちらつきに見えないか。重く感じたら画質「軽い」で消える
- [ ] （E2）トーンマップを入れた後の色が、くすんで見えないか（特にねじの赤・黄と、ネジまるの金色との差）
- [ ] （E2）設定「ねじ穴の形」を「色ごと」にしたとき、指で回しながら十字・トライウィング・二つ穴が見分けられるか（スマホの画面のねじ頭の大きさで）
- [ ] （E2）空の色が題材ごとに変わるのが、ステージを進めた時に唐突に見えないか
